Foldkit structures UI as data and explicit transitions. The Model is application state; a Message names an event; `update` computes a new Model and optional effects; `view` projects that Model into a declarative tree. Browser work is isolated into Commands, Subscriptions, and Mount actions rather than hidden inside rendering.

```ts compile
type Model = { readonly count: number }
type Message = { readonly _tag: 'Increment' } | { readonly _tag: 'Decrement' }
const update = (model: Model, message: Message): Model =>
  message._tag === 'Increment'
    ? { count: model.count + 1 }
    : { count: model.count - 1 }
```

The example is a pure transition; a running application also supplies a view and runtime configuration.
