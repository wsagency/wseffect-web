`@wsagency/wseffect-foldkit` is the core runtime, HTML builder, routing, and Model/update foundation. Its source is an independently maintained snapshot of Foldkit `0.168.0`, authored upstream by Devin Jameson. Install with the required peers: `pnpm add @wsagency/wseffect-foldkit@0.1.0-rc.1 effect@^4.0.5 @effect/platform-browser@^4.0.5`.

Use the core directly for a small application, or add `@wsagency/wseffect-app` for lazy pages and deployment-oriented browser capabilities. This package preserves upstream public subpath exports but is maintained separately from upstream; see [migration from upstream Foldkit](/migration/from-foldkit-upstream/). Browse [core concepts](/concepts/) and the generated module references.
