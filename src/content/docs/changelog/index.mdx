All five packages are coordinated at `0.1.0-rc.1`. This release candidate coordinates the published set; package changelogs report no runtime changes from RC.0 for this coordination release.

- **App:** versioned persistence decoding/migration contracts, generated runtime import isolation, page-load retry behavior, app-shared chunking, signal parsing/transport corrections, helper usage and limits.
- **Themes:** component/style package with generated tokens and component subpaths, portals, and themed accessible controls; RC.1 changes no runtime or stylesheet behavior.
- **Foldkit UI:** snapshot and integrated UI capabilities including virtual list customization and menu/select behavior; RC.1 changes no component runtime.
- **Foldkit:** core runtime, builder, routing and module surface from the attributed snapshot; review the source package's changelog for upstream chronology.
- **Vite plugin:** published build integration and explicit package surface; RC.1 changes no plugin runtime.

See the exact published [App](https://github.com/wsagency/wseffect/blob/v0.1.0-rc.1/packages/app/CHANGELOG.md), [Themes](https://github.com/wsagency/wseffect/blob/v0.1.0-rc.1/packages/themes/CHANGELOG.md), [Foldkit UI](https://github.com/wsagency/wseffect/blob/v0.1.0-rc.1/packages/foldkit-ui/CHANGELOG.md), [Foldkit](https://github.com/wsagency/wseffect/blob/v0.1.0-rc.1/packages/foldkit/CHANGELOG.md), and [Vite plugin](https://github.com/wsagency/wseffect/blob/v0.1.0-rc.1/packages/vite-plugin/CHANGELOG.md) changelogs for details. The `latest` npm tag currently follows this prerelease.
